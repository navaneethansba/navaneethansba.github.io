# Dr. Navaneethan Srinivasan — Executive Portfolio

GitHub Pages edition aligned to the current `navaneethan.co.in` executive website.

## Publish

Upload the contents of this folder to the repository:

`navaneethansba.github.io`

Then set GitHub Pages to deploy from:

`main` → `/(root)`

The page is self-contained: styling and visual assets are embedded in `index.html`, which avoids missing-image or missing-CSS issues on GitHub Pages.
